## 📌 Tentang Repository Ini
Repository ini berisi kumpulan *source code* web scraper yang akan terus diperbarui dan ditambahkan secara berkala. Semua scraper yang ada di dalam repository ini dikumpulkan di satu tempat agar mudah ditemukan dan digunakan.

## 📂 Struktur Folder
Semua script scraper dapat ditemukan di dalam folder `kumpulan_scrape`. 

```text
vellzyy-code/
└── kumpulan_scrape/
    └── detik_scraper.js
```
