# MPL Schedule Scraper

## Base URL
https://id-mpl.com/schedule

## Description
Scraper untuk mengambil jadwal pertandingan lengkap dari website MPL Indonesia. Data yang diambil meliputi tanggal, waktu, tim yang bertanding, serta skor (jika sudah tersedia).

## Installation
```bash
npm install
```

## Usage
```bash
node index.js
```
